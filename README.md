# Rétro Rallye

Un mini-jeu de voiture jouable dans un navigateur. Tout le jeu tient dans `index.html` : aucun outil à installer.

## Jouer

Ouvre `index.html` dans un navigateur. Utilise les flèches gauche/droite ou les touches A/D. Sur téléphone, touche les boutons à l'écran.

## Publier avec GitHub Pages

1. Crée un dépôt GitHub public nommé `retro-rallye`.
2. Ajoute `index.html` et `README.md` au dépôt.
3. Dans le dépôt, ouvre **Settings → Pages**.
4. Choisis **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`, et enregistre.
5. GitHub affichera l'adresse du jeu dans cette même section après quelques instants.

Pour inviter quelqu'un à contribuer : ouvre **Settings → Collaborators** et ajoute son nom d'utilisateur GitHub. Vous pourrez proposer vos modifications avec des pull requests.
