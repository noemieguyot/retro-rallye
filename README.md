# Rétro Rallye · Porsche 911

Un mini-jeu de course rétro jouable dans un navigateur. Toutes les voitures sont des Porsche 911 type 991 : Carrera 4S, Targa, coupé et cabriolet.

## Jouer

- Flèches gauche/droite ou A/D : changer de voie.
- Espace : tirer un missile.
- Ramasse les bonbons en forme d'écusson Porsche pour obtenir des missiles.
- Sur téléphone, utilise les boutons à l'écran.

Le jeu tient dans `index.html` et ne demande aucune installation.

## Publier avec GitHub Pages

1. Dans le dépôt, ouvre **Settings → Pages**.
2. Choisis **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`.
3. Enregistre : GitHub affiche ensuite l'adresse du jeu dans cette section.

Pour inviter quelqu'un à contribuer : ouvre **Settings → Collaborators** et ajoute son nom d'utilisateur GitHub. Vous pourrez proposer vos modifications avec des pull requests.
